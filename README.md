# cavusoglucagatay.com

Doç. Dr. Çağatay Çavuşoğlu — kişisel hekim sitesi (Netlify).

## Deploy (GitHub → Netlify)

1. Bu repo’yu GitHub’a push et (`MedicalasistanceAI/cavusoglucagatay-com`).
2. Netlify → Add new site → Import an existing project → GitHub → bu repo’yu seç.
3. Build ayarları: Build command boş, Publish directory: `.` (kök).
4. Domain: mevcut `cavusoglucagatay.com` domain’ini bu siteye bağla (eski manuel deploy’u değiştirir).
